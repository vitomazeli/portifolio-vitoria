# Portfólio - Vitória Moreno Tomazeli

## Como executar

Abra o terminal dentro da pasta que contém `package.json` e rode:

```bash
npm install
npm run dev
```

Se você tentou instalar a versão anterior, pode apagar `node_modules` e
`package-lock.json` antes de executar `npm install` novamente.

## Requisitos

- Node.js 18, 20 ou 22+
- npm

## Estrutura

- `src/App.tsx` - conteúdo da página principal
- `src/styles.css` - identidade visual e responsividade
- `src/main.tsx` - inicialização do React
- `vite.config.ts` - configuração do Vite
